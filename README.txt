電験クエスト Ver.0.6 — 音楽・効果音追加版

Ver.0.5の画像12枚を維持。Web Audio APIで4体別のオリジナルループBGMと効果音をブラウザ内で生成します（音楽ファイルのアップロードは不要）。

GitHubへの更新：index.htmlとsw.jsを置き換えてコミットしてください。assets内のWebP画像12枚はVer.0.5と同じものをassets/内に残します。

Safari/iPhoneはユーザー操作なしの音声自動再生を制限します。「音をON」ボタンをタップして再生を開始してください。BGM・効果音音量は端末内に保存します。

ゲーム進行データは以前と同じlocalStorageキーdenken-hunt-v03を使用。ブラウザのサイトデータを削除しないでください。

※本BGMはWeb Audioによる電子音の自動演奏です。録音されたオーケストラ音源ではありません。

BGM音量改善版: 初期BGM音量85%、BGMゲイン増加。index.htmlとsw.jsを両方更新してください。
